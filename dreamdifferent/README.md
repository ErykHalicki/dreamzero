# DreamDifferent

This directory holds project-specific materials for the DreamDifferent team
workflow built around DreamZero.

## Layout

- [`datasets/`](datasets): project-level dataset metadata, saved splits,
  analysis reports, and helper scripts.
- [`baseline/`](baseline): method-level baselines, notes, run logs, and
  submodules such as the OpenPI/pi0.5 baseline used for the Franka/ORCA
  bag-groceries comparison.
- [`docs/`](docs): DreamDifferent-specific documentation.
- [`scripts/`](scripts): DreamDifferent-specific helper scripts.

For the OpenPI/pi0.5 baseline work, start with:

- [`baseline/README.md`](baseline/README.md)
