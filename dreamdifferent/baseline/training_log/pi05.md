# Training Run Log

This file tracks the main DreamDifferent pi0.5 Franka/ORCA training runs in
this workspace. It is meant as a lightweight experiment diary, separate from
the setup-oriented README files.

```text
dreamdifferent/datasets/bag_groceries_communal/
```

## Current Training Ladder

The main training progression so far has used three total budgets with
`batch_size=16`:

- `8k` budget: `500` total steps
- `16k` budget: `1000` total steps
- `24k` budget: `1500` total steps

The `16k` and `24k` runs were started as new branch runs from the previous
checkpoint, so each earlier checkpoint directory remains preserved.

## Notes

- These runs use compact resumable adapter checkpoints rather than full model
  checkpoints.
- Each run keeps a rolling `adapter_history/` window of the latest 10
  checkpoints.
- The train-split-only runs are the ones intended for offline validation-based
  checkpoint selection.
- The all-episodes runs are closer to a latest-checkpoint robotics-style
  training/evaluation setup.
